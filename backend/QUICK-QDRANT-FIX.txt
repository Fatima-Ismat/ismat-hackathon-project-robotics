================================================
QDRANT CONNECTION ERROR - QUICK FIX
================================================

ERROR:
httpx.ConnectError: No connection could be made

CAUSE:
Qdrant server not running (need cloud or local)

================================================
SOLUTION 1: QDRANT CLOUD (5 MIN SETUP)
================================================

1. Sign up: https://cloud.qdrant.io (free)

2. Create cluster: "robotics-chatbot" (free tier)

3. Copy credentials from dashboard:
   - Cluster URL
   - API Key

4. Update backend\.env:
   QDRANT_URL=https://your-cluster.qdrant.io:6333
   QDRANT_API_KEY=your_api_key_here
   COLLECTION_NAME=robotics_textbook

5. Run ingestion:
   cd backend
   venv\Scripts\activate.bat
   python ingest.py

DONE! ✅

================================================
SOLUTION 2: LOCAL DOCKER (20 MIN SETUP)
================================================

1. Install Docker Desktop:
   https://www.docker.com/products/docker-desktop/

2. Run Qdrant:
   docker run -d -p 6333:6333 --name qdrant qdrant/qdrant

3. Update backend\.env:
   QDRANT_URL=http://localhost:6333
   QDRANT_API_KEY=
   COLLECTION_NAME=robotics_textbook

4. Run ingestion:
   cd backend
   venv\Scripts\activate.bat
   python ingest.py

DONE! ✅
